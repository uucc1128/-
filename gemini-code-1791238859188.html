連續函數 vs 不連續函數圖形視覺化

直觀上，連續函數就是「可以一筆畫完不中斷的曲線」。數學定義上，需滿足： $\lim_{x \to c} f(x) = f(c)$ （極限值等於函數值）

參考公式集

1. 指數與對數： $\log(ab) = \log a + \log b$ ， $10^{\log x} = x$

2. 等比數列前 $n$ 項和： $S_n = \frac{a(1-r^n)}{1-r}$

3. 正弦與餘弦定理： $\frac{a}{\sin A} = \frac{b}{\sin B} = 2R$ ， $c^2 = a^2 + b^2 - 2ab\cos C$

4. 極限與連續定義： 若 $\lim_{x \to c} f(x) = f(c)$，則 $f(x)$ 在 $x=c$ 處連續。
